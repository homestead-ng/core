+++ title = 'Household ERP: an early product concept' +++

This repository explores a shared, self-hosted workspace for household finances, purchasing, supplies, meals, maintenance, and coordination. The idea is still open for refinement; its modules and possible sequencing are not commitments. Read the working product concept.

The current code is a small Go web application foundation. Technical choices and behavior will be considered later, after the product boundaries are clearer.
